How we work
Sprints
One week long, starting and ending at the class session.

| Ceremony | When | Length |
| --- | --- | --- |
| Sprint review and standup | Class session, day 0 | Class time |
| Sprint planning | Day 0, right after class | 45 minutes |
| Written check in | Day 3 | 10 minutes each |
| Retrospective | Day 6, evening before class | 20 minutes |

Board
https://github.com/users/runveerk06/projects/1

Five columns. Backlog is anything not scoped yet. Ready is scoped and owned.
In Progress has a branch open and is limited to two items per person. In Review
is open pull requests. Done is merged work meeting the Definition of Done.

Definition of Done
Merged into main through a pull request
Approved by another member
Test workflow passed
New behavior has at least one test
Every acceptance criterion on the issue is met
Anything a teammate needs to run it is in the README
The issue closed itself through the merge
